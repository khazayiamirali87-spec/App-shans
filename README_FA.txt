پروژه اندروید «برنامه شانس»
=============================

این بسته یک پروژه Android Studio است که نسخه وب تعاملی برنامه شانس را داخل WebView اجرا می‌کند.
امکانات: گردونه قابل ویرایش، پرتاب سکه، پرتاب تاس، قرعه‌کشی اسامی، تاریخچه و تنظیمات.

نکته مهم:
این بسته APK کامپایل‌شده نیست. در محیط فعلی Android SDK و Gradle نصب نبودند، بنابراین امکان ساخت و امضای APK نهایی فراهم نشد.
برای تولید APK باید این پروژه در Android Studio با Android SDK نصب‌شده باز و Build شود.
فایل اصلی برنامه در مسیر app/src/main/assets/index.html قرار دارد.
